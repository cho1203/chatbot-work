# 챗봇 시스템 설계·개발 문서

새로운 확장형 챗봇 설계는 [신규 챗봇 시스템 통합 설계안](./next-chatbot/README.md) 한 문서에 전체 내용을 담았다. PostgreSQL 기반 pgvector 벡터 검색·Apache AGE 그래프 검색·pg_search BM25 도입 검토, TypeSafe AI Jev 판단 계층, 타입 안전한 계약, 조직 권한, 데이터 수명주기, API·화면, 구축·평가·복구를 다이어그램과 표로 설명한다. 종전 01~07 개별 파일은 통합본의 해당 절로 안내한다.

아래 `basic-chatbot`은 단일 호스트용 경량 설계로 보존한다. 두 설계의 스택·설정·API를 혼합하지 않는다. 신규 확장형 시스템을 구현할 때는 `next-chatbot`의 명시적 변경 결정이 우선한다.

경량 구성을 개발하려면 [기본 시스템 정의와 구축 순서](./basic-chatbot/README.md)에서 시작한다.

기존 네 가이드는 과거 구현과 그 검토 결과를 정리한 참고 자료다. 신규 통합 설계는 이 자료를 비교해 작성했으며, 이번 문서 통합에서 관련 앱 코드를 새로 감사하거나 신규 시스템을 구현한 것은 아니다.

|---|---|
| [신규 확장형 챗봇 통합 설계안](./next-chatbot/README.md) | 전체 설계·API·운영·검증 기록을 포함한 단일 기준 문서 |
| [기본 챗봇 개발 문서 묶음](./basic-chatbot/README.md) | 단일 호스트용 경량 시스템 설계와 구현 지침 |

기존 가이드는 원본 시스템을 설명한다. 신규 시스템의 포트, 스키마, API, 설정 기본값은 선택한 설계 묶음을 따른다.
