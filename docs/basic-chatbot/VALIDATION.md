# 문서 작성·검증 기록

검증일: 2026-09-18

## 수행한 확인

- 기존 개발 가이드 4종을 비교하고, 10장에 명시한 로컬 소스의 관련 구현을 정적으로 확인했다.
- 신규 안내 문서 12개(상위 docs 안내, 문서 묶음 안내, 본문 10개)의 Markdown 코드 펜스와 내부 파일 링크 49개를 검사했다. 오류는 없었다.
- JSON 예제 17개를 JSON 파서로 읽고 Python 예제 3개를 AST 파서로 구문 검사했다.
- 07장의 JavaScript SSE 파서를 실제 Node 런타임에서 실행했다. 한글 UTF-8을 1·2·3·7바이트 및 전체 프레임으로 나누는 경우, done 없는 종료, 잘못된 JSON의 7개 시나리오를 통과했다.
- 포트·파일 저장 경로·작업 상태·방문 세션·CSRF·offline CLI와 API의 저장소 접근 규칙을 문서 간 대조하여 정리했다.

## 수행하지 않은 확인

신규 챗봇 앱은 이번 요청에서 구현하지 않았다. 따라서 의존성 후보 전체 설치, Ollama 모델 다운로드·추론, DB 마이그레이션 실행, 실제 검색 품질 평가, 브라우저 종단 간 시험, Docker·Nginx 배포 성공을 주장하지 않는다. 이들은 [구현·인수 절차](./08-build-and-acceptance.md)와 [운영 절차](./09-operations.md)에 따라 실제 개발 단계에서 확인한다.

위 문서 수와 링크 수는 이 검증 기록을 추가하기 전의 본문 검사 기준이다. 이 기록을 포함한 링크 검사는 마지막 저장 후 다시 수행했다.
