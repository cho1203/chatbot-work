# MVBot

PostgreSQL 기반 신규 챗봇의 설계와 기존 개발 참고 자료를 관리하는 프로젝트입니다. 현재는 설계·자료 정리 단계이며 신규 챗봇 애플리케이션은 아직 구현하지 않았습니다.

## 시작 문서

- [신규 챗봇 시스템 통합 설계안](docs/next-chatbot/README.md): 전체 아키텍처, 데이터 계약, 검색, API, 구축·운영 기준
- [문서 안내](docs/README.md): 기존 개발 가이드와 경량 챗봇 설계

## 기본 설계

| 역할 | 솔루션 | 적용 상태 |
|---|---|---|
| 문서·권한·버전 관리 | PostgreSQL 일반 테이블 | 필수 기반 |
| 벡터 검색 | pgvector | 기본안 |
| 그래프 검색 | Apache AGE | P2 평가 후 활성화 |
| 키워드·BM25 검색 | ParadeDB pg_search | 도입 검토 후보 |

원본 파일은 객체 저장소에 보존하는 구조이며, TypeSafe AI Jev는 선택형 판단 계층으로 설계합니다. 실제 DB 확장 조합·검색 품질·운영 성능은 구현 단계에서 검증합니다.

## 프로젝트 구성

| 경로 | 내용 |
|---|---|
| `docs/next-chatbot/` | 신규 챗봇 통합 설계와 이전 장의 안내 링크 |
| `docs/basic-chatbot/` | 기존 경량 챗봇 설계 |
| `docs/DEVELOPER_GUIDE_*.md` | 기존 챗봇 개발 참고 가이드 |
| `data/samkwang/` | 원본 매뉴얼 PDF |
| `output/pdf/` | 번역 PDF, 그림 설명 및 번역 검증 기록 |

임시 추출물·문서 렌더링 결과·다운로드 도구가 있는 `tmp/`와 로컬 비밀 설정은 Git에서 제외합니다. 기존 개발 가이드의 내장 코드는 참고 자료이며 신규 애플리케이션 구현과 구분합니다.
